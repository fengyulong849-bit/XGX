# 小确闲 · 前端设计开发文档

> 一份文档让 AI 能完整写出前端界面。包含锁定主题、技术栈、设计系统、6 页 + 5 弹窗逐页规格、3D 桌宠实现、动效规范与界面文案。
> 版本 v2.0 ｜ 2026-08-14 ｜ 主题已锁定：深夜蓝 + 暖琥珀 + 衬线（Marble 骨架）

---

## 一、项目概览

**小确闲**——打工人的五分钟治愈站。核心：捏领导桌宠发泄 + 匿名吐槽共鸣 + 释怀销毁仪式，配合签到积分与打工人关怀。

**核心闭环**：预置桌例试玩 → 倒地触发登录 → 首次免费捏脸 → 桌宠发泄 → 吐槽共鸣 → 释怀销毁 → 关怀提醒与签到 → 积分复活领导。

**页面结构**：6 个独立页面 + 5 个首页内弹窗。

## 二、技术栈

| 项 | 选型 | 说明 |
|----|------|------|
| 框架 | 原生 HTML/CSS/JS | 单页应用，路由用 hash 或 history API |
| 3D 桌宠 | Three.js 0.160（ES Module + importmap） | P2 捏脸预览、P1 桌宠展示均用真 3D 低多边形模型 |
| 字体 | Google Fonts | EB Garamond + 思源宋体（衬线标题）、Inter + 思源黑体（正文）、DMMono（数据） |
| 图标 | Emoji + 内联 SVG | 不引入图标库 |
| 动效 | CSS @keyframes + Web Animations API | 销毁动画用 WAAPI |
| 响应式 | 移动优先，4 断点 | 见第九章 |

**Three.js 引入方式**：
```html
<script type="importmap">
{ "imports": {
  "three": "https://unpkg.com/three@0.160.0/build/three.module.js",
  "three/addons/": "https://unpkg.com/three@0.160.0/examples/jsm/"
}}
</script>
<script type="module">
import * as THREE from 'three';
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
</script>
```

## 三、设计系统（锁定主题）

### 3.1 主题定位
深夜蓝负责治愈降躁，暖琥珀负责情绪宣泄的火气。衬线标题让节奏慢下来，避免销售感与低幼感。

### 3.2 色彩 Token
```css
:root{
  --bg:#0E1A2B;        /* 深夜蓝底 */
  --bg-2:#0A1320;      /* 更深背景 */
  --surface:#142336;   /* 卡片底 */
  --surface-2:#1A2B44; /* 提升卡片 */
  --ink:#EDE8DD;       /* 暖米白正文 */
  --muted:#9AA8BC;     /* 次要文字 */
  --tertiary:#6B7A91;  /* 三级文字 */
  --rule:rgba(237,232,221,.08);     /* 分割线 */
  --rule-2:rgba(237,232,221,.14);   /* 强分割线 */
  --amber:#E8A33D;     /* 主强调：发泄火气/CTA/积分 */
  --amber-2:#F5B14C;   /* 胖度/次强调 */
  --rose:#D97A6C;      /* 烦躁/危险 */
  --blue:#6B9FD4;      /* 信息辅：共鸣/链接 */
  --calm:#6FB3A8;      /* 承受值/签到/成功 */
  --grad:linear-gradient(120deg,#E8A33D,#D97A6C); /* 主渐变 */
}
```
**状态条分色**：承受=calm / 烦躁=amber / 胖度=amber-2 / 脏度=muted

### 3.3 字体
```css
--serif:'EB Garamond','Noto Serif SC',serif;  /* 标题，斜体强调 */
--sans:'Inter','Noto Sans SC',sans-serif;       /* 正文 */
--mono:'DMMono',monospace;                       /* 数据/编号 */
```
- 标题：serif，font-weight 600，斜体词用琥珀渐变 `-webkit-background-clip:text`
- 正文：sans，16px，line-height 1.75
- Hero 标题：clamp(40px,6.2vw,66px)

### 3.4 圆角 · 阴影 · 间距
- 圆角：卡片 18–24px / 按钮 999px 胶囊 / 输入 14px / 小元素 10–12px
- 阴影：`0 8px 32px rgba(0,0,0,.3)` 卡片；`0 24px 64px rgba(0,0,0,.4)` 大卡；`0 0 28px rgba(232,163,61,.25)` 暖光
- 间距：4px 基准阶梯（4/8/12/16/24/32/48/64）

### 3.5 组件规范

| 组件 | 规范 |
|------|------|
| 主按钮 | `--grad` 背景 + `--bg` 文字 + 暖光阴影，hover translateY(-2px) |
| 次按钮 | 透明 + `--rule-2` 描边，hover 描边变 amber |
| 卡片 | `--surface` 底 + `--rule` 描边 + 暖色阴影；可选顶部 2px 渐变条 |
| 输入框 | 透明底 + `--rule` 描边，focus 描边变 amber，圆角 14px |
| 弹窗 | 磨砂遮罩 `backdrop-filter:blur(20px)` + 居中卡 + 顶部渐变条 + scale 300ms |
| 状态条 pill | 6px 高胶囊，分色填充，带流光扫过动画 |
| Toast | 顶部下滑，3s 自动消失，琥珀/rose/calm 三色 |
| 导航胶囊 | 磨砂背景 + blur，激活项琥珀文字 |

### 3.6 全息收藏卡（核心组件）
桌宠展示用高端 NFT 卡牌质感：
- 外层 conic 四色全息边框（amber/rose/blue/calm）12s 流转
- 内层深夜蓝径向渐变底 + 顶部 2px 渐变条
- 镭射斜向扫光 7s + 四角装饰角标
- 稀有度星标 + 编号 + 衬线名条
- 桌宠 3D 模型居中（Three.js），自转 + 鼠标视差
- 四状态条 + 四动作按钮（hover 顶部渐变条亮起 + 暖光）

### P3 释怀仪式

**定位**：全屏沉浸交互。写下/选择自己的吐槽，三选一销毁，完整看完动画获积分。

**布局**：四圆点步骤条（顶部）+ 全屏内容区。

**步骤条**：四个小圆点+标签（写下/选方式/销毁/释怀），当前琥珀发光，已完成 calm 绿+✓，连线随完成变绿。不用传统进度条。

**Step1 写下**：衬线输入卡，1–50 字实时计数，空内容按钮置灰。

**Step2 选方式**：预览烦心事 + 三卡（风吹散/揉成团/碎纸机）。

**Step3 销毁舞台**：全屏深色，米黄信纸卡居中，三种动画：
- **风吹散**：文字逐字变粒子，随机左右飘散+旋转+淡出（每字 60ms 错峰，WAAPI）
- **揉成团**：卡片缩皱变圆（borderRadius 8→50%）+旋转+抛飞出屏
- **碎纸机**：卡片切 12 条横向纸条，逐条旋转坠落，底部金属碎纸机口

**Step4 释怀**："烦心事，归零了。"打字机逐字（"归零"琥珀斜体）→ +100 积分弹跳 → 积分到账副文案 → 按钮（回到首页/再来一次）。

**界面文案**：
| 区域 | 文案 |
|------|------|
| 步骤 | 01 写下 → 02 选方式 → 03 销毁 → 04 释怀 |
| 输入标题 | 把最烦的那件事写下来 |
| 占位 | 写下最想销毁的那件事… |
| 字数 | 1–50 字 |
| 下一步 | 选一种方式了断 |
| 选方式标题 | 选一种方式了断 |
| 三卡 | 风吹散·向一侧滑动 / 揉成团·按压后甩出 / 碎纸机·长按启动 |
| 完成（加分） | 烦心事，归零了。+100 积分 |
| 完成（未满24h） | 销毁完成。发布未满24小时，本次不加积分。 |
| 跳过提示 | 跳过不奖励积分，但仍会删除这条吐槽。继续？ |
| 未满24h确认 | 这条吐槽发布未满24小时，销毁不加积分，仍要继续？ |
| 释怀按钮 | 回到首页 / 再来一次 |

**实现要点**：
- 风吹散：`text.split('')` 每字创建 span，WAAPI animate 飘散
- 揉成团：单个元素 WAAPI keyframes（scale+rotate+borderRadius+translate）
- 碎纸机：按高度切 12 个 div strip，逐条 WAAPI 下落
- 打字机：setTimeout 逐字追加，"归零"包裹 `<span class="em">`

### P4 个人中心

**定位**：登录后个人区。顶部概览 + 4 Tab。

**布局**：
- 顶部概览卡：积分余额大数字（mono/amber）+ 今日获得 + 连续签到徽章
- 胶囊 Tab：积分明细 / 我的吐槽 / 签到记录 / 账号管理（当前 Tab 琥珀下划线）

**Tab·积分明细**：钱包余额式大数字 + 时间线流水。收入 calm 绿前缀(+)/支出 rose 红前缀(-)，时间戳 muted。
- 示例：桌宠戳一戳 +10 / 签到 +100 / 共鸣收到 +10 / 复活领导 -500

**Tab·我的吐槽**：吐槽列表 + 新增共鸣提示 + "收下共鸣"按钮（一次领取）。
- 新增提示：新增 X 条共鸣，收下可得 +X 积分
- 收下后：已收下 +X 积分
- 空状态：还没发布过吐槽，去墙上看一眼？
- 标记：已释怀 / 淡忘中

**Tab·签到记录**：小网格日历，已签到 amber 圆点，连续连线。
- 里程碑：连续3天+100 / 7天+300 / 14天+600，之后每7天+300
- 断签：昨天断签了，今天重新开始，没关系

**Tab·账号管理**：修改密码 / 查看恢复码（提示丢失无法找回）/ 注销账号。
- 注销确认：注销后个人数据按规则删除，公开吐槽立即销毁，且无法恢复。确认注销？

### P6 规则与隐私

**定位**：公开说明页。左侧锚点导航 + 右侧卡片式长文。

**布局**：桌面端左侧固定锚点（平滑滚动），移动端折叠。每段规则用 card 包裹，标题衬线，正文无衬线。重要条款（15天保存/注销不可恢复）用 amber 左边框高亮。

**分段**：内容规则 / 匿名口径 / 15天保存规则 / 积分规则 / 敏感词处理 / 账号与注销。

**界面文案**（成稿）：
- **内容规则**：每天最多发布3条公开吐槽，每条1–50字纯文本。不设评论、私信、关注与排行榜，只保留共鸣。允许正常负面情绪，禁止违法、威胁、隐私、歧视、色情、诈骗与严重伤害性内容。
- **匿名口径**：吐槽不显示账号、昵称或头像，全站匿名。禁止填写手机号、邮箱、微信号、身份证、详细地址、工号等可识别信息。涉及具体对象请用"某领导""某同事""某公司"代称。
- **15天保存规则**：吐槽从发布起15天自然渐隐：卡片装饰逐渐变淡，正文始终可读。满15天后静默消失并删除，不提醒、不发积分、不留记录。
- **积分规则**：签到+100（含随机惊喜），吐槽入墙+50，共鸣+10，释怀+100，喝水+20，久坐+30，复活-500。所有数值服务端可配置。
- **敏感词处理**：前端预检即时反馈，服务端复检为入库硬门槛，浏览器无法绕过。
- **账号与注销**：账号不绑手机/邮箱/昵称/头像，仅账号+密码+恢复码。恢复码与密码同时丢失无法找回。注销后个人数据按规则删除，公开吐槽立即销毁。

## 六、3D 桌宠实现（Three.js）

### 6.1 场景搭建
```js
// 渲染器
renderer = new THREE.WebGLRenderer({canvas, antialias:true, alpha:true});
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.toneMapping = THREE.ACESFilmicToneMapping;

// 三点布光
scene.add(new THREE.AmbientLight(0x3A4A66, 0.55));          // 环境
key = new THREE.SpotLight(0xFFE0B0, 2.2, 30, Math.PI/5, 0.4, 1.5); // 暖主光
key.position.set(2, 9, 6); key.castShadow = true;
rim = new THREE.DirectionalLight(0x6B9FD4, 0.9);            // 蓝轮廓光
rim.position.set(-4, 5, -5);
fill = new THREE.DirectionalLight(0xE8A33D, 0.35);          // 琥珀填充
fill.position.set(4, 2, 4);

// 底座
base = Mesh(CylinderGeometry(2.2, 2.4, 0.18, 48), StandardMaterial(0x1A2536));
baseRing = Mesh(TorusGeometry(2.2, 0.04), emissive 0xE8A33D); // 发光环
ground = Mesh(CircleGeometry(6), ShadowMaterial(opacity 0.45)); // 接收阴影

// 控制
controls = new OrbitControls(camera, canvas);
controls.autoRotate = true; controls.autoRotateSpeed = 1.2;
controls.enablePan = false;
controls.minPolarAngle = Math.PI*0.2; controls.maxPolarAngle = Math.PI*0.62;
controls.target.set(0, 1.2, 0);
```

### 6.2 角色构建（8 维 → 3D 参数）

const SKINS = [0xF0C8A0, 0xE8B98A, 0xD4A574, 0x9C7B5A]; // 白黄棕黑
const SUITS = [0x2E3A4A, 0x1A1A1A, 0x4A4A4A, 0x3D2E1F]; // 深蓝黑灰棕

### 9.1 断点
| 断点 | 宽度 | 策略 |
