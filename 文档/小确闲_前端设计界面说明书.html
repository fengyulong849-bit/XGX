一、设计系统（锁定主题）

主题定位

深夜蓝负责治愈降躁，暖琥珀负责情绪宣泄的火气。衬线标题让节奏慢下来，呼应"五分钟治愈站"的定位，避免销售感与低幼感。

色彩 Token

bg
surface
surface-2
ink
amber
rose
blue
calm
  • --bg #0E1A2B 深夜蓝底　--ink #EDE8DD 暖米白正文
  • --amber #E8A33D 主强调（发泄火气 / CTA / 积分）　--rose #D97A6C 烦躁/危险
  • --blue #6B9FD4 信息辅色（共鸣/链接）　--calm #6FB3A8 承受值/签到/成功
  • --grad = amber→rose，用于标题强调字、主按钮、稀有度条

字体 · 圆角 · 组件

  • 标题：EB Garamond + 思源宋体（衬线，斜体强调）　正文：Inter + 思源黑体　数据：DMMono
  • 圆角：卡片 18–24px / 按钮 999px 胶囊 / 输入 14px
  • 按钮：主按钮 amber→rose 渐变 + 暖光阴影；次按钮透明描边；幽灵按钮仅文字
  • 卡片：surface 底 + rule 描边 + 暖色阴影分层；顶部可加 2px 渐变条
  • 弹窗：磨砂遮罩 + 居中卡 + 顶部渐变条 + scale 进出 300ms
  • 状态条 pill：承受=calm / 烦躁=amber / 胖度=amber-2 / 脏度=muted

P1 首页（主页）

定位

试用与登录共用的核心页。首屏桌宠在前，吐槽释怀紧随，不做纯营销落地页。承载桌宠互动、倒计时、签到、吐槽墙、释怀入口、关怀提醒。

布局

  • 顶部：浮动胶囊导航（Logo + 链接 + 下班倒计时胶囊 + 登录/试玩按钮）
  • Hero：衬线大标题 + 副标题 + 双 CTA
  • 桌宠收藏卡：全息卡牌框 + SVG 手办 + 稀有度 + 四状态条 + 四动作
  • 签到紧凑条 + 柔和吐槽流跑马灯 + 吐槽墙网格 + 释怀三选一 + 关怀提醒

P2 捏脸DIY

定位

登录后权益。8 维捏脸配置驱动 SVG，支持随机/默认/保存/同步/分享。首次注册赠送一次免费捏脸（满血新领导）。

布局

  • 左侧：360° 实时预览舞台（桌宠自转 + 鼠标接管）
  • 右侧：8 维配置面板（滑块/选项组）+ 随机/默认/保存按钮 + 分享链接

界面文案

页头

眼镜、胡子含"无"选项
基础肚子与动态胖度分离

P3 释怀仪式

定位

全屏沉浸交互。用户写下/选择自己的吐槽，三选一销毁方式，完整看完动画获释怀积分。满 24 小时才加分。

布局

  • 步骤条：写下 → 选方式 → 销毁 → 释怀
  • 烦心事输入卡 + 三选一方式卡 + 全屏销毁动画舞台 + 结果反馈

界面文案

步骤条
01 写下烦心事 → 02 选择方式 → 03 销毁 → 04 释怀
输入卡
标题：把最烦的那件事写下来
输入占位：写下最想销毁的那件事…
字数提示：1–50 字
下一步：选一种方式了断
三种销毁方式
风吹散：🌬️ 风吹散　动作提示：向任意一侧滑动
揉成团：📄 揉成团　动作提示：连续按压后甩出
碎纸机：✂️ 碎纸机　动作提示：长按启动直到完成
销毁进行中
跳过：跳过 （跳过仍删除，但不发积分）
结果反馈
完成（满24h，加分）：烦心事，归零了。+100 积分
完成（未满24h，不加分）：销毁完成。发布未满 24 小时，本次不加积分。
跳过提示：跳过不奖励积分，但仍会删除这条吐槽。继续？
未满24h确认：这条吐槽发布未满 24 小时，销毁不加积分，仍要继续？

布局

  • 顶部：头像区 + 积分余额 + 连续签到天数
  • Tab：积分明细 / 我的吐槽 / 签到记录 / 账号管理

P5 找回密码

定位

未登录可达。账号 + 恢复码 + 新密码重置。成功后旧恢复码作废生成新码。

布局

  • 居中窄表单卡，三字段 + 提交按钮

界面文案

页头
标题：找回密码
副：输入注册时生成的恢复码，重置密码。
表单字段
账号：账号（牛马编号） 占位：输入你的账号
恢复码：恢复码 占位：粘贴恢复码
新密码：新密码 8–32 位，字母/数字/符号任两类
提交：重置密码
结果反馈
成功：密码已重置。旧恢复码已作废，请保存新的恢复码。
失败：恢复码无效或已过期，请检查后重试。
频率限制：尝试过于频繁，请稍后再试。

P6 规则与隐私

定位

公开可达的说明页。上线硬门槛：隐私说明、内容规则、匿名口径、15 天保存规则、账号注销说明就绪。

布局

  • 手风琴/分段长文，左侧锚点导航

界面文案

分段标题
内容规则 / 匿名口径 / 15 天保存规则 / 积分规则 / 敏感词处理 / 账号与注销
内容规则
每天最多发布 3 条公开吐槽，每条 1–50 字纯文本。
不设评论、私信、关注与排行榜，只保留共鸣。
允许正常负面情绪，禁止违法、威胁、隐私、歧视、色情、诈骗与严重伤害性内容。
匿名口径
吐槽不显示账号、昵称或头像，全站匿名。
禁止填写手机号、邮箱、微信号、身份证、详细地址、工号等可识别信息。
涉及具体对象请用"某领导""某同事""某公司"代称。
15 天保存规则
吐槽从发布起 15 天自然渐隐：卡片装饰逐渐变淡，正文始终可读。
满 15 天后静默消失并删除，不提醒、不发积分、不留记录。
积分规则
签到 +100（含随机惊喜），吐槽入墙 +50，共鸣 +10，释怀 +100，喝水 +20，久坐 +30，复活 -500。
所有数值服务端可配置，上线两周后据真实行为调整
敏感词处理
前端预检即时反馈，服务端复检为入库硬门槛，浏览器无法绕过。
账号与注销
账号不绑手机/邮箱/昵称/头像，仅账号 + 密码 + 恢复码。
恢复码与密码同时丢失时无法找回，以保护数据安全。
注销后个人数据按规则删除，公开吐槽立即销毁。
